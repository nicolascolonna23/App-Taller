# Reglas del repositorio

## Ramas

- **Todos los cambios se suben a la rama `DEMO-Y-PRUEBAS`.** No crear otras
  ramas de trabajo ni subir a ninguna otra.
- **A `main` solo se sube cuando el dueño lo pide explícitamente.** Hasta
  entonces, nada de pushes, merges ni pull requests hacia `main`.
- Antes de empezar, actualizar: `git fetch origin && git checkout DEMO-Y-PRUEBAS && git pull origin DEMO-Y-PRUEBAS`.

## Textos de la aplicación

- La interfaz habla en castellano neutro e impersonal: sin explicaciones
  dirigidas al usuario, sin voseo ni tuteo, sin opiniones. Etiquetas y
  mensajes cortos y descriptivos.
